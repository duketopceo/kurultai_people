# Brand assets (proposal)

Status: proposal written 2026-10-11. The owner signs off logos.

- `logo.svg` / `logo-dark.svg`: 32-unit mark. Ring (radius 12.5, stroke 3) is the parent Kurultai "council ring". Inside: three horizontal bars (stroke 2.4, round caps, the last one shorter) meaning short excerpts, and a 2.1-radius ember dot at the end of the last bar, the citation marker.
- `logo-adaptive.svg`: the same drawing with an embedded `prefers-color-scheme` media query, for `<img>` use in the plugin UI (an `<img>` cannot inherit page colours). It follows the OS scheme, not Agent Zero's theme toggle.
- `wordmark*.svg`: mark plus "Kurultai Memory" in Liberation Sans Semibold, outlined.
- Colours: ink `#16171C` / `#ECE8DF`; ember `#9A5B00` (light) / `#E8A33D` (dark). Same as `kurultai/DESIGN.md`.
- Previews in `preview/` (resvg + oxipng).
